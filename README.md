# TREVol / Macro Cocina Fit — AWS infrastructure

Static site (S3 + CloudFront) + serverless order backend
(API Gateway + Lambda + DynamoDB). No EC2, no ALB, no NAT Gateway.
Estimated cost running all month: **$0.50 – $1.50**, with an alarm at $3.

## Install Terraform (once, on your machine — not in this chat)

```bash
brew install terraform          # Mac
# or: https://developer.hashicorp.com/terraform/install
terraform version                # confirm it ran
```

You also need the AWS CLI configured with your credentials:
```bash
aws configure
```

## Step 1 — Bootstrap (ONLY the first time)

Creates the state bucket and the lock table. This uses local state on purpose.

```bash
cd bootstrap
terraform init
terraform apply
```

Confirm the output names (`trevol-terraform-state`,
`trevol-terraform-lock`) match what's written in
`envs/prod/providers.tf`. If you changed `project` from the default
`trevol`, adjust that file by hand.

## Step 2 — Configure variables

```bash
cd ../envs/prod
cp terraform.tfvars.example terraform.tfvars
```

Edit `terraform.tfvars`: put your real email in `alert_email` (that's
where spend alerts arrive). Leave `domain_active = false` for now.

## Step 3 — First apply (no domain yet)

```bash
terraform init
terraform apply
```

When it finishes, the `site_url` output gives you a URL like
`https://d111111abcdef8.cloudfront.net` — the site is already up and
running there, order form included.

## Step 4 — Once the AWS email confirming the domain arrives

Edit `terraform.tfvars`:
```hcl
domain_active = true
```

```bash
terraform apply
```

This connects Route 53, validates the HTTPS certificate automatically
(can take a few minutes on the first apply while ACM validates), and
moves the site to `https://trevolcamaguey.com`.

## Delivery: worker panel, tracking and routing

| Page | Who | What |
|---|---|---|
| `/panel.html` | kitchen + riders | Day's orders grouped by delivery slot, status buttons, fix a pin on the map, reschedule, best bike route for a batch, "Salí" / "Entregué", live ETAs. Beeps on new orders. Installable on the phone home screen. |
| `/seguir.html` | customer | Live status + ETA of their order. Link is shown after checkout and kept in a "Mi pedido" pill. Shows the rider on a map only while the order is `en_camino`. |
| checkout (`/`) | customer | Picks a delivery slot ("lo antes posible" or franjas), the address is estimated on a map from the text (Camagüey street grammar) and the customer can drop a pin — **a customer pin always wins**. |

### Worker key
One shared key for the whole team. It is generated by Terraform:
```bash
cd envs/prod
terraform output -raw worker_key      # the key
terraform output panel_url            # where to open it
```
Open `panel_url`, type the key once (the phone remembers it). Changing it: `terraform taint random_password.worker_key && terraform apply`.

### Rider location without keeping the screen on
Phones freeze web pages in the background, so the panel does not depend on it:
1. Once per trip the rider opens the TREVol bot in Telegram → 📎 → Location → **Share live location** ("until I turn it off"). The phone can be locked. Telegram sends updates to `POST /api/telegram/webhook` (registered automatically by `terraform apply`, protected by a secret header).
2. Every **Entregué** press re-anchors the ETA clock, so customers get a good estimate even with no GPS at all.
3. ETAs are computed when read (no per-update work) from the planned leg times, the last fresh position and the deliveries already made.

Authorize a rider: he writes `/start` to the bot, the bot replies with his numeric id, add it to `telegram_worker_ids` in `terraform.tfvars` and apply. Cost: $0 (no extra services).

### Address vocabulary (Camagüey)
`lambda/order_handler/camaguey.json` is the street catalog used by the geocoder. Build it once from OpenStreetMap (needs internet; stdlib only):
```bash
python3 tools/build_gazetteer.py --out lambda/order_handler/camaguey.json
python3 tools/build_gazetteer.py --check "Maceo #45 e/ Cisneros y Avellaneda, Rpto Garrido"   # try an address
```
It prints a coverage report (how many streets/repartos/places). Then teach it local speech in `lambda/order_handler/aliases.json` (`abbreviations`, `streets`, `areas`, `landmarks`: what people say → official name) — best done with someone from Camagüey. Without `camaguey.json` everything still works, but pins come out as "sin pin" and the worker fixes them in the panel; each fixed address is remembered for the next order.

Confidence order: customer pin → remembered address → between two streets → corner → landmark → street only → neighborhood only. The panel shows which one each order got.

### New tfvars (all optional)
`kitchen_lat`, `kitchen_lng` (also movable from the panel menu), `delivery_slots` (JSON list), `prep_minutes`, `slot_lead_minutes`, `telegram_worker_ids`, `worker_key` (leave empty = generated). See `terraform.tfvars.example`.

### Known limits
One rider and one trip at a time. House numbers are not interpolated (pin is on the block, the customer/worker adjusts it). Routing uses the public OSRM bike server and OSM tiles (no SLA): if OSRM is down the panel falls back to straight-line estimates and says so; to fix it for good point `Route.base` in `site/route.js` to your own OSRM.

### Tests
```bash
python3 -m unittest tests.test_geo tests.test_build_gazetteer tests.test_handler tests.test_logistics
node tests/test_route.js
python3 tests/e2e_browser.py     # needs playwright + chromium; runs the 3 pages against the real Lambda code
```

## Updating the page content

Just edit the files under `/site` and run again:
```bash
terraform apply
```
Terraform only uploads what changed (compared by hash).

## Tearing it all down (to spend nothing while it's not in use)

```bash
cd envs/prod
terraform destroy
```
The bootstrap (state bucket) stays — never destroy it unless you want
to abandon the project entirely.

## Structure

```
bootstrap/        S3 bucket + DynamoDB table for Terraform state (once)
envs/prod/        The real "entrypoint": composes every module
modules/frontend/ S3 + CloudFront (the site)
modules/dns/      Route 53 + ACM certificate (HTTPS)
modules/backend-api/ DynamoDB + Lambda + API Gateway (the order form)
modules/budget/   AWS Budgets alarm at $3/month
lambda/order_handler/ Python source for the Lambda that saves orders
site/             HTML/CSS/JS for the site (index, panel, seguir) — this is what gets uploaded to S3
tools/            build_gazetteer.py (street catalog from OpenStreetMap)
tests/            unit tests + browser end-to-end test
```
